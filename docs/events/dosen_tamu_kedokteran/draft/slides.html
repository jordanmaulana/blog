Errors

[ 02 ]

Indicator

99.9%SLO → error budget 0.1%
> 1.44%errors for 1 hour → page (burn rate 14.4)
> 0.1%errors for 3 days → ticket (burn rate 1)

Remediation

Always use randomized exponential backoff when scheduling retries.

Limit retries per request. Don’t retry a given request indefinitely.
